True Wireless Earbuds

TWS-01

  • Driver size, 8–11mm dynamic
  • IPX4+ sweat rating
  • Case battery ≥ 400mAh

Portable SSDs

STG-04
  • Read/write speed (MB/s)

  • IP rating, if any
  • Capacity (TB)
